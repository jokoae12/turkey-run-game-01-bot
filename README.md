Feast or Flight: A Turkey's Great Escape — a side-view auto-runner in which a turkey flees Thanksgiving dinner across three stages (Farmyard, Barn, Kitchen) while a farmer chases it with a pitchfork. Dodge fences, ovens and carving knives, grab corn and golden feathers, hide in haystacks, dash to freedom — reach 1500 m to earn the pardon, or get caught for dinner. Pure HTML5 Canvas and vanilla JavaScript, no libraries, synthesized WebAudio sounds, keyboard controls, and a real autopilot for deterministic screenshots.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
